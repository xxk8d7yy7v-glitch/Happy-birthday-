# 🌸 Blossom Wishes

A cinematic birthday & anniversary wish generator with a cherry blossom tree animation.

## How to Deploy on GitHub Pages

### Step 1 — Create a GitHub Repository
1. Go to [github.com](https://github.com) and sign in
2. Click the **+** icon → **New repository**
3. Name it `blossom-wishes` (or anything you like)
4. Set it to **Public**
5. Click **Create repository**

### Step 2 — Upload the Files
1. Click **Add file** → **Upload files**
2. Drag and drop both:
   - `index.html`
   - `blossom.html`
3. Click **Commit changes**

### Step 3 — Enable GitHub Pages
1. Go to your repo → **Settings** tab
2. Scroll down to **Pages** in the left sidebar
3. Under **Source**, choose **Deploy from a branch**
4. Select branch: **main**, folder: **/ (root)**
5. Click **Save**

### Step 4 — Get Your URL
After 1–2 minutes, your site will be live at:
```
https://YOUR-USERNAME.github.io/blossom-wishes/
```

That's your creation page! Share the generated links with loved ones.

## How It Works

1. **index.html** — The creation page. Fill in the recipient, occasion, message, and theme, then click **Plant Your Blossom** to get a shareable link.

2. **blossom.html** — The animation page. When someone opens the link, they see a cinematic intro screen. They tap anywhere and:
   - A glowing seed falls from where they touched
   - The seed lands and a cherry blossom tree grows from the ground
   - The canopy blooms into a **heart-shaped** cloud of colored petals
   - Petals drift down like snow
   - The personalised message fades in transparently over the tree

## Notes

- All data is encoded in the URL — no server or database needed
- Works on mobile and desktop
- The link encodes: recipient name, sender name, message, occasion, and theme
- Share via WhatsApp, iMessage, email — wherever you like
